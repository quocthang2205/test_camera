Kiểm tra pixel lỗi camera

Chọn loại test → thả ảnh → kiểm tra thông số → Phân tích Ctrl+Enter

1Loại kiểm tra

2Ảnh chụp

Kéo thả cả thư mục ảnh vào trang: ảnh tự vào đúng ô theo tên file (dark_, white_, red_ …).

Số ảnh phân tích

3Điều kiện chụp

Ghi vào file kết quả. Bỏ trống camera / ISO / phơi sáng = đọc từ EXIF.

4Thông số phân tích

Chỉ hiện thông số mà loại test đang chọn có dùng. Ô tô màu = khác mặc định.

Thả ảnh vào đây để tự xếp vào ô theo tên file
